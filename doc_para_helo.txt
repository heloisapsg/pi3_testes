Ao dar git push, a Helô precisa saber primeiro:
Para qual repositório eu estou dando push?

Para os testes da Helô ou para o projeto final?

-   Se é para o projeto:
    ______________________________
    |    git pull origin main    |
    |____________________________|

-   Se é para os testes da Helô:
    _____________________________________________
    |    git pull origin-helo testes_da_helo    |
    |___________________________________________|

Então fica:

|    Repository    |      Branch      |    Quem    |
| ---------------- | ---------------- | ---------- |
|      origin      | `main`           |    grupo   |
|    origin-helo   | `testes_da_helo` |    Helô    |

MAS se a Helô quiser mostrar que o teste deu certo, ela vai dizer:

    __________________________________________________________
    |       git push origin-helo testes_da_helo:main         |
    |________________________________________________________|
